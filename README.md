# Divine Fly Fishing

Astro website for Divine Fly Fishing (Bhutan).

Live preview: https://basanta-svg.github.io/divineflyfishing/

## Develop

```sh
npm install
npm run dev      # http://localhost:4321/divineflyfishing/
npm run build
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
`astro.config.mjs` sets `site` and `base` for the project-site URL; change both when moving to a custom domain.
